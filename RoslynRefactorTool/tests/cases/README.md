# RoslynRefactorTool hermetic test cases (TRANSFORM_CONTRACT §9.1)

Each subdirectory is a self-contained "owning project" (a single `Site.cs`)
used as the `--owning-dir` for one `RoslynRefactorTool` invocation. The cases
are driven by the committed, repeatable harness
[`tools/generation/tests/test_roslyn_tool.py`](../../../tools/generation/tests/test_roslyn_tool.py),
which runs as part of `pytest tools/generation/tests/`.

Positive cases (assert `applicable=true`, the `seam` descriptor matches the
contract, and the rewritten output COMPILES against the tool's bundled refs):

| dir | family | line | method | receiver | kind |
|---|---|---|---|---|---|
| `ilogger/`    | `ILogger.LogInformation` (Case A, extension) | 16 | LogInformation | ILogger | Extension |
| `httpclient/` | `HttpClient.GetAsync` (Case C, async non-virtual) | 17 | GetAsync | HttpClient | NonVirtual |
| `isp/`        | `IServiceProvider.GetRequiredService<T>` (Case B, generic extension) | 18 | GetRequiredService | IServiceProvider | Extension |
| `wrapper_doc_ctor/` | `ILogger.LogInformation` into a class whose ctor already has `<param>` XML doc | 18 | LogInformation | ILogger | Extension |

Analyzer-hardening assertions (TRANSFORM_CONTRACT §9.1; make generated/injected
edits survive strict analyzers in real repos):

| test | fixture | guards against |
|---|---|---|
| `test_generated_wrapper_file_has_autogen_header` | `ilogger/` | SA*/IDE0xxx on the generated wrapper file (opens `// <auto-generated/>` + `#nullable enable`) |
| `test_nullable_disable_site_injects_param_without_annotation` | `wrapper_nullable_disable/` | CS8632 (`?` in a `#nullable disable` context) |
| `test_doc_commented_ctor_gets_param_tag_for_injected_param` | `wrapper_doc_ctor/` | CS1573 (injected param missing `<param>` doc) |
| `test_candidate_fallback_picks_matching_arity_overload` | `overload_candidate_arity/` | overload misselection when `symInfo.Symbol` is null (orleans:0116): the candidate fallback must pick the arity/type-matching overload, not the first-listed one |


> **Case B (`isp/`) is currently XFAIL.** The tool returns `unbound_receiver`
> for the framework generic extension `GetRequiredService<T>` even though the
> source compiles with the same bundled refs (an in-repo generic extension
> binds fine). This is a tool-side reference-identity limitation flagged for
> Watney — see `.squad/decisions/inbox/beck-via-seam-tests.md`. Both
> `wrapper_interface` and `parameterize_dependency` are exercised for the
> working families.
